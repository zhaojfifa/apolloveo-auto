1 · 脚本

脚本来源

粘贴脚本

选择一种方式提供脚本：粘贴正文 / 上传脚本文档 / 选择已有脚本。系统会自动生成产品句柄并存入会话内的脚本素材库；运营无需自己拼写句柄。

提交后会被存入会话内的脚本素材库（在线临时存储；网关重启会清空）。脚本正文不会发送给任何外部模型、厂商或引擎。

支持 .txt / .md 纯文本；最大 64 KB。系统会在本地读取正文，再走与「粘贴脚本」相同的入库流程。

仅在你已经在 Asset Supply / 内部脚本库中预先发布了脚本时使用。当前阶段没有可视化的脚本选择器；如果你没有现成句柄，请用「粘贴脚本」或「上传脚本文档」。

架构师 / 工程师：手动指定不透明脚本句柄（技术引用）
本节仅在 ?technical=1 下可见。普通运营不会看到此节。 外部网页 URL（https:// / http://）与对象存储桶 URI（s3:// / gs://）不是产品内不透明句柄，会被入口拒绝。

接受方案：content:// / task:// / asset:// / ref://，或纯令牌 ID。 「铸造空句柄」只分配一个产品句柄，不存任何正文；如果你只是要把脚本传进来，请改用上面三个标签页。

链路

提交后会发生什么

  1. 系统把脚本正文存入会话内的脚本素材库，并生成一个不透明的产品句柄。
  2. 句柄进入产线，触发解析与变体方案生成（当前为确定性骨架，不调用任何外部模型）。
  3. 跳转到任务工作台，可查看任务摘要 / 脚本结构 / 变体方案 / 生成进度 / 候选评审 / 交付摘要。
  4. 成片生成能力上线后，候选评审区会出现可预览的成片；当前阶段会显示「暂无可预览成片」。
