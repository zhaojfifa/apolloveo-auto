链路

提交后会发生什么

  1. 系统把脚本正文存入会话内的脚本素材库，并生成一个不透明的产品句柄。
  2. 句柄进入产线，触发解析与变体方案生成（当前为确定性骨架，不调用任何外部模型）。
  3. 跳转到任务工作台，可查看任务摘要 / 脚本结构 / 变体方案 / 生成进度 / 候选评审 / 交付摘要。
  4. 成片生成能力上线后，候选评审区会出现可预览的成片；当前阶段会显示「暂无可预览成片」。
