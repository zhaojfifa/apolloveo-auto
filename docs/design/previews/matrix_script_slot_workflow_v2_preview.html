批量再次生成 → V1 / V2 对比 → 确认 / 丢弃

步骤 5–6 · 最关键
⑤ 批量再次生成入口（在选定镜头改动之后一次性生成，而非每张卡片各自再生成）
已选择 3 个镜头调整，生成 / 更新 V2 预览 在你处理完选定镜头之后统一触发一次再次生成。
① 已有一版 V2 候选（先前已把 Shot 03 的上传素材生成进 V2）。
② 本次「生成 / 更新 V2 预览」会在同一个 V2 候选上，把这 3 个镜头一起更新进去——不是另开一版，是更新当前候选。
③ 当前主视频始终是 V1；只有你在下方明确「确认 V2 为主版本」，V2 才会成为主视频。确认前 V1 不变、交付不变。
本次将更新进 V2 的镜头：Shot 04（补充） · Shot 05（替换） · Shot 06（替换）。其余镜头保持不变。
