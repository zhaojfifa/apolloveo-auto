## 2. Provider Orchestrator

New `gateway/app/services/matrix_script/provider_orchestrator.py` (Part A).

* **Target shot selection:** the real-visual storyboard shots (distinct local assets) —
  **shot01 海边 Hook / scene_reference**, **shot02 小番茄产品特写 / product_reference**,
  **shot03 拿起小番茄 / product_reference** — plus the operator's active shot if valid; ordered by
  shot order. (shot04/shot05 are semantic reuses → not targeted; honest backbone fallback.)
* **Provider strategy:** per shot — build script-derived prompt (deterministic Prompt Builder via
  `generation_plan_view.build_provider_prompt_for_shot`), optionally **strengthen with Gemini**,
  then call the proven `akool_image_to_video_capability.generate_shot_clip_akool` (hosts material →
  create → poll → download → normalize to 1080×1920/30fps).
* **Retry strategy:** on a non-fatal failure, **call Gemini to rewrite** the prompt (simpler/safer)
  and retry **once** — retry happens ONLY when Gemini actually produces a rewrite (not a blind
  re-send). Credential-missing never retries.
* **Fallback strategy:** after a recorded failure, the shot degrades to the ffmpeg backbone proxy.
  **No silent fallback** — every attempt yields an honest `ShotTrace`.
* **No silent fallback / no fake success:** bounded by a global attempt budget (Owner cap **≤ 5**
  video attempts); the per-shot trace records `provider_attempted / provider_status /
  hosted_input_created / task_created / poll summary / clip_downloaded / normalized /
  consumed_into_final / fallback_reason / latency / attempts`. A fallback-only batch reports
  `provider_failed`, never a fake clip.

## 3. Gemini Role

New `gateway/app/services/matrix_script/gemini_prompt_refiner.py` (Part B). A backend production
helper (NOT a UI selector, NOT a source of truth).

* **Gemini used:** YES (live, this run). Model **`gemini-2.5-flash`** — see the env finding below.
* **Inputs:** script segment, narration line, visual goal, motion instruction, material role,
  product constraints, and (on retry) the previous redacted failure reason.
* **Outputs:** a strengthened English provider prompt + negative list (runtime-transient, never
  operator-surfaced) + a fixed **operator-safe** Chinese summary ("AI 已强化生成要求：更具体的画面、
  光线与运镜描述。"). Retry path emits a distinct summary.
* **Prompt example (live, redacted-safe):** deterministic base "sunlit cherry tomatoes in a glass
  bowl by the sea" → Gemini-strengthened "Extreme close-up, glistening cherry tomatoes, water
  droplets rolling, vibrant red, soft cinematic light, gentle rotation, macro lens, subtle rack
  focus, shallow depth of field…". (The raw English payload stays runtime-transient; the operator
  sees only the Chinese summary + the existing operator-safe AI 生成要求.)
* **Retry/refinement:** retry rewrites use `source=retry_refined`; in this run all three shots
  succeeded on the first attempt, so no retry fired.
* **Unavailable behavior:** if the key/base/model are missing OR the call/parse fails, the refiner
  **falls back to the deterministic Prompt Builder** (`source=deterministic`, `available=False`) —
  it never pretends Gemini ran. (Verified: with the decommissioned model it fell back honestly to
  deterministic; the system still produced 3/3 — see §10 first smoke.)
