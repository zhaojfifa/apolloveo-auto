{# ===================== Sidebar · 链路 ===================== #}
链路

提交后会发生什么

  1. 生成脚本理解：Hook / Body / CTA / 卖点。
  2. 生成视频方案：分镜、背景、B-Roll、商品素材位。
  3. 生成角色与音频计划：角色、旁白、字幕、音乐。
  4. 进入工作台确认方案，再生成主视频。
技术链路（架构师视图）

    POST /tasks/matrix-script/new
  • 正文入库

    会话内 in-process 存储；不持久化
  • 空句柄
    POST /tasks/matrix-script/source-script-refs/mint
  • 任务工作台
    GET /tasks/{task_id}
  • 交付中心
